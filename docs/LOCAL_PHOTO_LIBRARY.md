# 桌面端本地图库（本地原图、元数据索引）

## 使用方式
进入 **照片 → 本地图库**，默认自动列出当前系统 **Pictures/图片** 文件夹下的图片，包括子文件夹。Windows 还会尝试识别 OneDrive/Pictures，Linux 会读取 XDG_PICTURES_DIR。点击 **添加照片文件夹** 可接入其他本地目录，选择仅保存目录授权，不复制任何照片。支持移除添加的目录和手动刷新。

此功能不导入原图副本：它保留照片原路径，列表来自当前文件系统；图片被移动或删除时刷新列表即反映变化。图库扫描后异步将本地照片的文件信息、EXIF 拍摄时间、GPS 经纬度写入统一 SQLite `photos` 表（`storage_type=local`），供足迹的现有照片推荐与照片绑定功能使用。

## 支持与限制
- 当前可预览 JPG/JPEG、PNG、WebP、GIF、BMP 和 TIFF；HEIC/HEIF/RAW 暂不支持。
- 每次最多索引 25,000 张，最多 24 个手动来源，递归深度上限为 24。缩略图限制并发数为 4，图片尺寸上限为 120 MP，原图上限 160 MB。
- 图片缩略图缓存在 LifeTrace 数据目录的 photo-library-thumbnails；图片原件**不复制、修改或上传**。数据库仅保存索引元数据和文件路径。\n- 新扫描到的本地图片会后台读取 EXIF/GPS，完成索引后可以参与足迹推荐。照片来源变化后，重新扫描会更新信息；失效路径标记为 unavailable，不自动删除足迹关联。
- IPC 仅允许读取系统图库或用户明确添加的文件夹；符号链接不纳入递归扫描。没有配置的任意路径无法通过图片读取命令访问。
- 旧版 **已保存的照片** 页签不再显示；扫描遇到与历史已导入照片字节级 SHA-256 完全一致的本地原件，会先迁移相关足迹照片关联，再删除 LifeTrace 管理的重复原件、缩略图和旧照片记录。**未能验证存在相同本地原件的旧照片不会删除**，以防误删唯一副本。\n- **私密相册**继续保留并受密码保护，不作为旧副本清理目标。

## 局域网导入移除
已经移除手机配对二维码、LAN 上传 HTML、设备配对命令和 3443/3445 局域网上传监听。仅保留绑定 127.0.0.1:3444 的既有本机存档照片预览服务，兼容此前保存的媒体文件。保留历史 SQLite 表，不清空任何以前已保存的照片。
