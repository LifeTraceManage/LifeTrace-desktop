# 中国旅行足迹与照片地点绑定设计

## 目标
Travel 只面向中国境内旅行。地图默认展示中国，地点以省/自治区/直辖市、城市和具体地点组织。照片与地点的最终关联以 `place_id + latitude + longitude` 表示，省市名称用于检索和展示。

## 照片绑定规则
1. 照片存在 EXIF GPS：导入时保留经纬度，可直接进入照片地图；用户仍可把它归属到已有地点。
2. 照片没有 EXIF GPS：不丢弃、不禁用。用户点击照片后必须选择一个已有地址/地点，再创建照片关联。
3. 地址选择以 LifeTrace 已保存地点为第一版数据源。地点包含名称、省、城市、国家代码和经纬度；因此无 GPS 照片绑定地点后会继承该地点坐标并显示在地图上。
4. 如果所需地址不存在，先“添加地点”，填写省、市、具体地点及坐标，再回到照片选择器绑定。
5. 照片原文件不移动、不复制；Travel 只保存关联。

## 中国地图约束
- 默认中心：中国中部，约 `[104.2, 35.8]`。
- 限制地图浏览范围到中国及近海范围，避免 Travel 退化成全球地图。
- 默认缩放适合全国视图。
- 在线底图失败时必须显示可理解的错误；离线 PMTiles 仍可作为替代。
- 地点数据默认 `country=中国`、`countryCode=CN`。

## 无 GPS 交互
照片地图 -> 添加照片 -> 扫描相册：
- 有 GPS：按钮显示“有定位”，点击直接关联。
- 无 GPS：显示“需选择地址”，同时展示“绑定地址”下拉框。
- 用户先选择省市/具体地点对应的已有地点，再点击无 GPS 照片。
- 保存时把 `placeId` 与地点经纬度写入 photo link。
- 未选择地址时不允许误创建无坐标照片关联，并给出明确提示。

## 数据模型
现有 `travel_places` 已包含 country/country_code/province/city/latitude/longitude；`travel_photo_links` 已包含 place_id/latitude/longitude，因此本阶段无需数据库迁移。

## 验收标准
- Travel 打开默认看到中国视角。
- 地图不能无限拖到全球其它区域。
- 新建地点默认国家“中国”、国家代码“CN”。
- 有 GPS 照片可直接加入照片地图。
- 无 GPS 照片不会变灰不可操作；选择已有地址后可以绑定。
- 无 GPS 照片绑定后继承地点坐标，并能在照片地图对应地点显示。
- 未选地址点击无 GPS 照片时有明确提示且不产生错误数据。
- 已关联照片不可重复关联。
